# e-plantShopping

## Paradise Nursery Shopping Application

An online plant shopping application offering a variety of house plants categorized into Air Purifying Plants, Aromatic Fragrant Plants, Insect Repellent Plants, Medicinal Plants, and Low Maintenance Plants.

### Features
- Landing page with company overview and "Get Started" button
- Dynamic product listing page with plant categories, details, and "Add to Cart" functionality
- Responsive navigation bar with dynamic cart count badge
- Shopping cart page with subtotal, total amount calculation, quantity increment/decrement, item deletion, and checkout alert
- Built with React, Redux Toolkit, and Vite
